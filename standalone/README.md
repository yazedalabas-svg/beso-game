# لا تطلع يا بيسو — النسخة المطوّرة

افتح beso.html في Chrome أو Edge. الرسوم والموديلات والأصوات مدمجة داخل الملف، ولا تحتاج حسابًا أو اشتراكًا. اضغط «ابدأ الكابوس» ثم اسمح للماوس بالتحكم. ESC للإيقاف.

WASD للحركة، الماوس للنظر، E للتفاعل، F للفلاشلايت، Shift للركض القصير، C للانحناء، N لدفتر الأدلة والنهايات. البطارية محدودة ويمكن جمع بطاريات داخل المتاهة. التقدم يحفظ محليًا في نفس المتصفح.

الغرفة: خذ الفلاشلايت من الطاولة والمفتاح من تحت السرير. افحص الصور واقلب واحدة للحصول على الرسالة. ترتيب قفل الذكريات: فنجال، ساعة، باب.

النهايات:
1. الهروب الحقيقي: اجمع الرسالة والتسجيل ثم اختر «اخرج بالدليلين». لو فاتتك الرسالة، توجد نسخة عند بداية المتاهة. التسجيل قرب الاستراحة.
2. الكوميدية: اختر «افتح باب الحفلة». لا تحتاج أدلة.
3. الرعب المفتوح: اختر «ادخل الباب المجهول».
4. السرية: اجمع الدليلين ثم اختر «واجهه في غرفة التحكم».

بعد كل نهاية يمكنك إعادة الكاتسين أو الرجوع لاختيار مختلف. كل مشهد مدته نحو 14 ثانية وله حوار وحركة كاميرا ومكان مختلف.

مرزوق يستخدم موديل القط المرفق والـ Rig. يبحث عند آخر موضع رآك أو سمعك فيه، يحترم الجدران، يركض لفترة ثم يتعب. طفّ النور واكسر خط النظر. منطقة الاستراحة آمنة.

الصوت: طنين فلورسنت، احتكاك وخبطات اتجاهية، خطوات مكتومة وراء الجدران، نبض وتنفس مع الركض، تعليقات مرزوق، تسجيل صوتي وحوارات النهايات. من الإعدادات تقدر تغير مستوى الصوت وتخفف الوميض والفزعة.

الموديلات من ملفات المستخدم، جرى تصغيرها للاستخدام في المتصفح. تحريك الـ Rig برمجي. أصوات الحوار مصنّعة وليست تسجيل شخص حقيقي. المؤثرات مولّدة باستخدام Web Audio. تصميم المتاهة مولّد مع خامات متكررة مصممة للجدران والأرضية؛ ملف rec-room الكبير لم يُستخدم كخريطة لعب.
