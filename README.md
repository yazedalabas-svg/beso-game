# لا تطلع يا بيسو | Don't Go Out, Beso 🐱🔦

لعبة رعب وكوميديا ثلاثية الأبعاد تفاعلية بمنظور الشخص الأول، مبنية بالكامل على الويب باستخدام **Three.js** و **React 19** و **Vite**.

تدور أحداث اللعبة في ممرات مظلمة وغامضة مستوحاة من ممرات الـ Backrooms، حيث يجد "بيسو" نفسه محتجزاً ويحاول الهروب بينما يطارده "مرزوق". تحتوي اللعبة على ألغاز بيئية، إدارة موارد (البطارية والستامينا)، وأربع نهايات سينمائية درامية وكوميدية كاملة الإخراج بأسلوب أنمي "جوجو" (JoJo's Bizarre Adventure).

---

## 🎮 مميزات اللعبة

- **منظور الشخص الأول (First-Person Controller):** حركة كاملة مع فيزياء المشي والركض والانحناء وإدارة طاقة التحمل (Stamina).
- **إضاءة ورعب تفاعلي:** فلاشلايت بمخزون بطارية محدود، انقطاعات كهربائية طارئة ومفاجئة، وأصوات محيطية ثلاثية الأبعاد تنبهك بقرب المطارد.
- **ذكاء اصطناعي تفاعلي للمطارد (Dynamic Pursuer AI):** مرزوق يستجيب للأصوات، يرصد ضوء الفلاشلايت، ويتبع مسارات مخصصة في المتاهة مع نظام ذكريات واستكشاف.
- **ألغاز بيئية وتجميع أدلة:** أسرار الغرفة، استعادة شريط الذكريات، وجمع الوثائق للوصول إلى المخرج الحقيقي.
- **٤ نهايات سينمائية كاملة (JoJo Style Cinematic Endings):**
  1. **المواجهة خلف الباب (The Truth):** قتال ستاندات ملحمي (Stand Battle) ينتهي بضربة الفِنِشر القاضية.
  2. **المصالحة المسمومة (The Comedy):** جلسة شاي وماء لوز مشبوهة.
  3. **أنت شخص رهيب (The Time Loop):** اعتراف درامي مؤثر داخل الممرات.
  4. **سر الحماية (The Secret / Control Room):** اكتشاف حقيقة التجربة في غرفة المراقبة.
- **إصدار مستقل يعمل بدون إنترنت (Standalone Offline HTML):** إمكانية تجميع اللعبة بالكامل في ملف HTML واحد بحجم ~10.8 ميجابايت مدمج به جميع المجسمات والأصوات والخامات بدون الحاجة لأي خادم أو اتصال بالشبكة.

---

## 🛠️ التقنيات المستخدمة

- **Three.js (WebGL):** محرك التصيير ثلاثي الأبعاد، الإضاءة والمؤثرات البصرية.
- **Procedural Rigging & Animation:** تحريك الشخصيات وتعبيرات الوجه وإيماءات اليد بدون تحميل ملفات أنيميشن ضخمة.
- **React 19 & TypeScript:** الواجهات التفاعلية وإدارة حالة اللعبة.
- **Web Audio API:** مؤثرات صوتية مكانية ثلاثية الأبعاد (3D Spatial Audio).
- **Vite & Cloudflare Workers:** بيئة البناء والتطوير السريع.

## 🚀 التشغيل والتطوير المحلي

### المتطلبات
- **Node.js:** الإصدار 22 فما فوق.
- **npm**

### تثبيت الاعتماديات
```bash
npm install
```

### التشغيل في وضع التطوير
```bash
npm run dev
```

### فحص الكود واختبارات الجري والمطاردة
```bash
npm test
```

### بناء النسخة المستقلة (Single-File Offline HTML)
```bash
npm run standalone
```
يتم إنشاء ملف اللعبة المستقل الكامل في: `standalone/beso.html`

### النشر على Render

المشروع مجهز للنشر كـ Static Site حتى لا يتم تشغيل `wrangler dev` في بيئة الإنتاج:

- **Build Command:** `npm run build`
- **Publish Directory:** `dist/client`

لا تضع Start Command في إعدادات Static Site؛ Render يخدم ملفات `dist/client` مباشرة.
